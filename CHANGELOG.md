# Changelog

## 0.2.0 — 2026-11-08

- Add six teaching tools: teacher mathematics checks, complete-question activities and feedback, slider-based function plots, MathLive input, a private student panel and Anki text export. Local MCP now exposes 25 tools; remote HTTP MCP exposes 21.
- Preserve original mathematical domain exclusions and separate student submissions, hints, teacher demonstrations and actual learning records. Learner profile and teaching agreements are configurable shared context.
- Add mouse side-button hand/previous-tool shortcuts, canvas wheel zoom and right-click object/region annotation picking. Browser asset hashes prevent stale frontend caching.
- Update Android to 0.2.2 with the new bundled whiteboard controls. Public signing identity is retained; it remains different from the original private installation's identity.
- Expand isolated tests and Windows/Linux CI with pinned Python mathematics dependencies. GeoGebra assets and Anki installers remain optional local software and are not redistributed.

Real desktop adapter acceptance remains version-specific. Automated checks do not certify physical mouse mappings or real-phone interaction.
